# Roami 🌍

### iOS Travel Exploration & Planning App Prototype

Roami is an interactive iOS travel application prototype developed using Swift, SwiftUI, SceneKit, and Xcode, with development assistance from OpenAI Codex.

## About the Project

I developed Roami to explore how technology can create a more engaging, organized, and informative travel-planning experience. The concept brings together destination discovery, saved trips, interactive exploration, and travel safety information in one mobile interface.

The app is a working prototype, with several features using sample data and others still in development.

## Key Features

- **Interactive 3D Globe:** Explore a rotatable globe and visualize saved destinations.
- **Destination Discovery:** Browse trending destinations and search for cities and countries.
- **Destination Information:** Explore travel highlights, activities, accommodations, dining, and shopping.
- **Travel Safety:** View prototype risk indicators, advisory categories, and detailed safety-alert screens.
- **Trip Organization:** Browse upcoming trips, pinned destinations, and sample day-by-day itineraries.
- **User Profile:** View and edit profile information and personalize a profile photo.
- **Connected Navigation:** Move between Home, Explore, My Trips, and destination details.

## Project Status

**Prototype / Work in Progress**

Roami is an educational and exploratory project rather than a production-ready travel service. Some itineraries, risk ratings, and safety alerts are illustrative sample data, not verified live travel advisories. Certain features remain under development.

Using Codex during development does not mean the application itself currently includes an AI-powered feature.
