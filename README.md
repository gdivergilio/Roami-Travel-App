# Roami 🌍
### iOS Travel Exploration & Planning App Prototype

Roami is an interactive iOS travel application prototype developed using **Swift, SwiftUI, SceneKit, and Xcode**, with AI-assisted development through **OpenAI Codex**.

## About the Project

I developed Roami to explore how technology can make travel planning more interactive, organized, and informative. My goal was to design a mobile experience that brings destination discovery, trip planning, and travel safety information together in one place.

The prototype allows users to explore destinations through an interactive 3D globe, browse travel recommendations, save favorite locations, view sample itineraries, and explore destination-specific safety information.

Throughout development, I focused on creating a cohesive user experience with intuitive navigation, interactive visual elements, and an accessible interface.

## Key Features

- **Interactive 3D Globe:** A rotatable globe built using SceneKit, designed to display pinned travel destinations.
- **Destination Discovery:** Browse trending destinations, explore cities and countries, and search for locations.
- **Destination Guides:** Explore destination highlights, cultural experiences, outdoor activities, accommodations, dining, and shopping.
- **Travel Safety:** View prototype risk ratings, weather warnings, safety advisories, and location-based alert details.
- **Interactive Maps:** Explore geographic areas associated with destination safety alerts using MapKit.
- **Trip Organization:** View upcoming trips, saved destinations, and sample day-by-day itineraries.
- **User Profiles:** View and edit profile information, including travel preferences and profile photos.
- **Connected Navigation:** Navigate between Home, Explore, My Trips, and destination detail screens.

## Project Status

**Working Prototype | Ongoing Development**

Roami is a personal development project intended to demonstrate mobile application design, technical experimentation, and product development.

Several features currently use sample data, including travel itineraries, risk scores, and safety alerts. The safety information is illustrative and should not be interpreted as current or verified travel advisories.

Additional functionality, data integrations, and interface improvements may be developed in future iterations.
